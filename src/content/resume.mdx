### Paper Mania | Team Leader / Server Developer<Footnote>총 4명 규모</Footnote>
**2025년 2월 - 2025년 10월 | 종이 세계에서 던전을 돌파하는 사이드뷰 액션 RPG**

스테이지 진행, 플레이어 재화, 게임 데이터 관리 기능을 담당하는 RPG 서버를 개발했습니다. <br />
데이터 접근 구조 최적화와 동시성 제어를 통해 응답 성능 및 데이터 정합성을 개선했습니다.

#### 주요 작업
- Redis 캐싱을 통한 API 응답 성능 개선 (<Metric>평균 28.02ms → 8.66ms, 약 69% 단축</Metric>)
  - 읽기 비중이 높은 API에 Cache-Aside 전략을 적용해, 150,000건 부하에서 <Metric>처리량을 1,765 → 5,556 RPS(약 3.1배)</Metric>로 향상
  - 캐시 미스 시 동시 요청이 DB로 몰리는 Cache Stampede를 Key 단위 Semaphore 동기화로 방지
- 정적 게임 데이터 메모리 적재로 레벨업 처리 개선 (<Metric>10레벨 상승 기준 평균 289.15ms → 114.15ms, 약 60% 단축</Metric>)
  - 레벨업 단계마다 반복되던 레벨 정의 DB 조회(요청당 최대 11회)를, 서버 시작 시 CSV를 메모리에 적재하는 구조로 바꿔 0회로 제거
  - 개발 지식이 없는 기획자가 Google 스프레드시트 수정만으로 밸런스 수치를 조정할 수 있는 데이터 파이프라인 구축
- 트랜잭션 기반 보상 지급 정합성 보장
  - 클리어 기록, 골드, 종이조각, 경험치를 갱신하는 보상 지급을 하나의 트랜잭션으로 구성
  - 오류 발생 테스트로 리포지토리가 트랜잭션과 분리돼 롤백되지 않던 문제를 발견해 수정하고, 수정 후 전체 롤백을 검증
- 테스트 및 CI/CD 자동화 환경 구축
  - xUnit, Moq 기반 단위 테스트를 작성하고, PR마다 GitHub Actions로 빌드와 테스트를 자동 실행
  - main 병합 시 Docker 이미지 빌드부터 SSH 배포까지 자동화 (평균 약 1분)
  - 민감 정보는 Azure Key Vault와 GitHub Secrets로 분리해 관리
- 팀 리딩 및 프로젝트 개발 관리
  - 5인 팀의 개발 목표 및 일정 수립, 역할 분담, 기술적 의사결정 주도
  - 클라이언트 개발자와의 API 명세 협의 및 서버 개발 일정 관리

**주요 기술**: ASP.NET Core, .NET 9, C#, PostgreSQL, Dapper, xUnit, Redis, Azure Key Vault, GitHub Actions, Swagger

  - 누적 응답 크기 1MB 초과 시 원본 스트림 전달 방식으로 전환하여 전체 응답 적재 방지
